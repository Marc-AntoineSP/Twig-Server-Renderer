# Dismissible alert example

Include catalogue/awui/alert/component.html.twig with validated props and only.
Requires daisyUI 5, Tailwind 4 and the registered catalogue--awui--alert controller.
The consumer must merge manifest defaults before including the template; templates
intentionally use strict variables. The installer README generator should show a
complete example with all props. Props are text; no raw HTML is accepted.
This fixture is source-only. It has not been rendered or compiled in this kit environment.
