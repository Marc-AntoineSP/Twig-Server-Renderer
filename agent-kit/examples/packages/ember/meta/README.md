# Ember theme source example

Warm orange, pale cream and rose; typography uses local system fonts.
theme.json is canonical. Source app.css/fragment/typography demonstrate the M04
generator contract and are not compiled output. M04 must add preview.css after
running Tailwind and verify its appearance and round-trip behaviour.
When installing multiple themes, consolidate the shared @theme inline bridge once.
CSS source paths assume these files remain under assets/styles/catalogue/awui/ember/.
